# Data provenance

`demo/` contains deterministic **synthetic** LOBSTER-shaped CSV files generated by `scripts/make_demo_data.py`. They provide an offline fixture for data pipeline checks and are not observations from an exchange.

`raw/` is ignored by Git. `scripts/download_sample.py` retrieves an official [LOBSTER sample](https://data.lobsterdata.com/info/DataSamples.php) from `https://php.lobsterdata.com/info/sample/LOBSTER_SampleFile_{TICKER}_2012-06-21_10.zip`. The source supplies aligned `message` and `orderbook` CSV files. The [format documentation](https://data.lobsterdata.com/info/DataStructure.php) defines event types and states that prices are stored as dollar prices multiplied by 10,000.

The repository does not redistribute LOBSTER's ZIPs. The provider's page gives the applicable data terms. Raw research data and generated reports remain outside version control.
